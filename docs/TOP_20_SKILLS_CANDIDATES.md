# Top 20 Claude Skills Candidates

Based on community popularity (GitHub stars), utility, and "High-Integrity" alignment, here are the top 20 skills we can import/adapt.

## 💻 Coding & Development

1.  **`test-pilot` (Webapp Testing)**: Interactive Playwright runner that debugs failures. (Critical for High-Integrity).
2.  **`code-review` (Sentry Style)**: Analyzes diffs for security, secrets, and performance issues.
3.  **`systematic-debugging`**: Enforces a 4-step debug loop (Investigate -> Hypothesis -> Fix -> Verify).
4.  **`tdd-architect`**: Strict Test-Driven Development flow. Writes tests _first_, verifies failure, then writes code.
5.  **`mcp-builder`**: Auto-generates boilerplate for new MCP servers (connecting Claude to new tools).
6.  **`api-designer`**: Enforces OpenAPI/Swagger best practices when designing backend routes.
7.  **`git-task-master`**: Advanced git automation (worktrees, complex mergies, release tagging).

## 🚀 DevOps & Infrastructure

8.  **`aws-cloud-architect`**: Best-practice CDK/Terraform generator.
9.  **`docker-pilot`**: Manages containers, debugs Dockerfiles, and optimizes build caching.
10. **`env-guardian`**: Scans `.env` files and config maps for security risks (Secrets, PII).

## 📊 Data & Analysis

11. **`sql-sage`**: Writes optimized SQL queries and explains execution plans (great for Supabase).
12. **`knowledge-grapher`**: Extracts entities from docs to build a "Project Brain" (Mermaid/JSON).
13. **`data-cleaner`**: Python-based skill to clean messy CSV/JSON datasets.

## 📝 Documentation & Knowledge

14. **`spec-writer`**: Interviews you to generate specific PRDs or RFCs.
15. **`doc-genie`**: Auto-generates `README.md` and inline docs from code analysis.
16. **`mermaid-architect`**: Specializes in drawing complex system diagrams from code.

## ⚡ Productivity & Workflow

17. **`linear-manager`**: CRUD for Linear issues (if acceptable to integrate).
18. **`notion-scribe`**: Pushes meeting notes or decisions to Notion (requires MCP).
19. **`email-drafter`**: Creates polished communication based on technical updates.
20. **`skill-creator`**: A meta-skill that helps you build _new_ skills interactively.

## 🎯 Selection Guide

- **Immediate Value**: `test-pilot`, `code-review`, `systematic-debugging`.
- **Long-term Value**: `spec-writer`, `knowledge-grapher`, `mcp-builder`.
