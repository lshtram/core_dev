# Restoring non-Git data

GitHub contains the durable source, tests, documentation, agent guidance,
configuration templates, migrations, and package lockfile.

- `node_modules/` is regenerated with `npm ci`.
- `.next/` and TypeScript build information are generated by the build and
  type-check scripts.
- `.env.local` is machine-local and may contain credentials. Recreate it from
  `.env.template` and the authorized password or service configuration; never
  commit it.
- Finder metadata and tool caches are disposable.

The complete retirement-time directory is also retained in the independently
checksummed external `projects.tar` archive created on 2026-09-06.
