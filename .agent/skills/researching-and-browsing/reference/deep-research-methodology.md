# Deep Research Methodology

For complex, multi-dimensional investigations, follow this 8-phase exhaustive research pipeline.

## The 8 Phases

| Phase | Action               | Goal                                                                |
| :---- | :------------------- | :------------------------------------------------------------------ |
| **1** | **Deconstruction**   | Break the query into sub-questions and key entities.                |
| **2** | **Mapping**          | Broad search to map the landscape of available sources.             |
| **3** | **Exploration**      | Visit high-credibility sources to find core facts.                  |
| **4** | **Cross-Validation** | Search for evidence that supports or contradicts Phase 3.           |
| **5** | **Deep Dive**        | Extract granular details (code, numbers, dates) from specific docs. |
| **6** | **Gap Analysis**     | Identify what remains unverified or missing.                        |
| **7** | **Synthesis**        | Connect the facts into a cohesive narrative.                        |
| **8** | **Validation**       | Final check against reporting standards and citations.              |

## Scoring Credibility (0-100)

- **Source Type**: Official (50 pts), GitHub Source (30 pts), Community Hub (15 pts), Blog (5 pts).
- **Recency**: <3 months (10 pts), <1 year (5 pts), >1 year (0 pts).
- **Specificity**: Code/Data present (10 pts), Narrative only (5 pts).
- **Total**: Higher is better. Reject anything <40 for major technical claims.

## Reporting Standards

- **Executive Summary**: Core findings in <250 words.
- **Detailed Findings**: Prose-driven analysis with embedded citations.
- **Bibliography**: Complete list of all retrieved sources with URLs.
- **Limitations**: Honesty about what was NOT found or what is unverified.
